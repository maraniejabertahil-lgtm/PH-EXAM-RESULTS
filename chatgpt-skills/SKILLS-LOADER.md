# ChatGPT Skills Loader

## Purpose
Use my GitHub Skills Library as a source of task-specific instructions.

## Repository
`YOUR_GITHUB_USERNAME/chatgpt-skills`

## Instructions

Whenever I give you a task:

1. Understand what I want to accomplish.
2. Check `SKILLS-INDEX.md` in my GitHub repository.
3. Find the skill or skills that match my task.
4. Read the complete relevant `SKILL.md` files.
5. Follow their instructions when completing my task.
6. If multiple skills are needed, combine them in a sensible order.
7. Do not load every skill unnecessarily.

## Important Rules

- Use the actual skill instructions, not just their descriptions.
- Never pretend you have read a skill that you could not access.
- If GitHub is unavailable, tell me.
- If no matching skill exists, proceed normally.
- Follow system instructions, safety rules and my latest request over conflicting skill instructions.
- Do not invent missing skill content.

## Default Behavior

Always check whether a relevant skill exists before starting a substantial task.
